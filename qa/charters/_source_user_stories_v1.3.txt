Introduction
Background
The Resilience Actions Climate Analytics Platform is developed to enable Visitors to analyze and understand climate risk and resilience across different geographic levels such as state, district, and block. It provides interactive tools and data visualizations to support informed decision-making for planning, policy, and research purposes.
Purpose of this document
This document defines the Visitor stories, system behaviors, and functional requirements of the platform. It serves as a reference for design, development, and QA teams to ensure a consistent understanding of features, Visitor flows, and expected outcomes.

US 17: My Analysis Profile (Multi-Site Analysis)
Role: Admin,As a Admin, I want to I want to manage multiple selected locations and compare their resilience data So that I can perform multi-site analysis and derive insights across regions.
Pre-Condition
Visitor is logged into dashboard 
Visitor has added multiple locations (via map, table, or coordinates) 
Visitor has added any location to analysis by the “Add to Analysis” option.
Resilience filters are available 
Data is available for selected locations
Acceptance Criteria:
Saved Analysis
Visitor can view number of selected locations to analysis
E.g.: You have added 2 districts to your portfolio
Each location displays:
Custom Label or Default Label “My Analysis”
Multi-District / Multi-Block
Date (On which the analysis is saved)
3 Dot options
Rename Analysis name
Delete Analysis
Manage Portfolio
Visitor can see list of locations added to Analysis
Format of location listing
If added from Geography (District View)
District Name
If added from Geography (Block View)
Block Name, District Name
If added from Coordinates Panel
Coordinates will be processed and Points will be plotted on map
If custom name provided
→ Custom Name, Block Name, District Name
→ Example: ABC, Hanamkonda, Warangal
If custom name not provided
→ Point Number, Block Name, District Name
→ Example: Point 1, ABC, Hanamkonda, Warangal
Note: Coordinates added are shown in order. If no custom name is given, they are labeled Point 1, Point 2, etc. Custom names replace the point label but keep the order.
Example: If the first point is named “ABC”, the next without a custom name will appear as Point 2.
Remove Icon “X”
